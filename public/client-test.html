Simulación de Sitio Cliente

Esta página simula un sitio web externo (como una intranet o portal) que tiene embebido el script de Welcome Popup Sync.

Si ya has visto los mensajes, deberías ver un icono de campana verde en la esquina inferior derecha. Haz clic en él para ver el historial.

Para volver a ver el popup inicial, puedes limpiar la sesión desde el Portal de Configuración.
